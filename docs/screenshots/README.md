# Public screenshot set

This directory contains the reviewed `v0.1.0` public screenshot set. Every capture uses Prumo's fictional demo data or a purpose-built synthetic import fixture.

Every image must:

- use only the repository's fictional demo dataset;
- show a visible **Demo data** label where financial values appear;
- contain no personal names, paths, volume names, files, categories, notes, browser history, extensions, notifications, or operating-system account details;
- be reviewed at its original resolution before commit;
- use stable filenames referenced by the README and release notes;
- include useful alt text where it is embedded.

Expected files:

```text
web-dashboard.png
local-dashboard.png
dark-mode.png
light-mode.png
import.png
simulator.png
mobile.png
privacy-mode.png
file-selection.png
```

The Web dashboard chart represents the complete portfolio, so its change and headline total are immediately understandable to a first-time visitor. The Local dashboard preserves the product's existing category-filter UI and is visibly marked as a read-only demonstration.
